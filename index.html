Transparent by design

What this tool does — and does not do.

The public website provides information only. Backup execution and Google authorization take place in the owner's local rclone installation.

01 / ACCESS

Limited Drive permission

The desktop workflow requests drive.file access, allowing it to manage files created by or granted to this app, rather than unrestricted access to unrelated Drive content.

02 / PROCESSING

Encryption before transfer

When the encrypted remote is used, rclone crypt encrypts backup contents and file names locally. Google Drive still processes encrypted object metadata such as sizes and timestamps.

03 / CONTROL

No public backup service

This is not a hosted file-upload portal. The website offers no login form, does not receive OAuth tokens or backup contents, and does not run backup jobs.

Why Google account access is requested

Google authorization is used solely by the local rclone Drive connection to create, read, check, and manage backup objects in the authorized Google Drive account. The website itself does not request Google account access. Review the complete Privacy Policy before authorizing.
